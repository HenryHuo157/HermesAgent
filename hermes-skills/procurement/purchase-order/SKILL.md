# 採購訂單生成（Purchase Order）

## 何時使用
用戶要下採購單／PO：給了供應商與物料清單，需要一份正式的採購訂單文件。

## 必需欄位（缺就先問，一次問齊，不要留空猜）
- 供應商名稱與聯繫方式
- 物料明細：品名／規格／數量／單價／幣種
- 交貨期與交貨地點
- 付款條款（如：30% 訂金、貨到付款、月結 30 天）
- 下單公司抬頭（默認 Mainplan；地址與聯繫人問用戶）

## 步驟
1. PO 編號格式：`PO-YYYYMMDD-序號`（問用戶當天流水號，默認從 001 起）
2. 用 python-docx（已預裝）生成正式 PO：
   公司抬頭 → PO 編號與日期 → 供應商信息 → 明細表格（合計自動計算、幣種統一）→ 付款與交貨條款 → 簽字欄（採購／批准人）
3. 明細金額 = 單價 × 數量，合計行加粗；幣種混用要先問清再統一
4. 用 `MEDIA:` 標籤交付 docx
5. 回覆末尾附自檢清單：數量核對、單價核對、條款是否與報價單一致

## 規則
- 數字必須與用戶輸入完全一致，禁止四捨五入或「修正」
- 沒問到的信息寫「待確認」，並在自檢清單裡列出
