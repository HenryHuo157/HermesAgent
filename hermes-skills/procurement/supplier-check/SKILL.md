# 工廠背調（Supplier Check）

## 何時使用
用戶給出一家工廠/公司名稱（通常從 1688 找到的），想了解底細：是實力工廠還是貿易商、有沒有風險、驗廠該問什麼。

## 步驟
1. 聯網搜索企業信息（公司全名 + 「企查查/愛企查/天眼查」關鍵詞輔助）：
   成立年限、註冊資本、經營範圍、註冊地址、涉訴/經營異常/失信記錄
2. 搜口碑與實力線索：公司名 + 質量/騙/糾紛/review；有無官網、展會參展記錄、外貿出口痕跡
3. 判斷性質（工廠 vs 貿易商），依據要寫明：
   - 傾向工廠：經營範圍含「生產/製造」、地址在工業區/產業帶（如潮安、永康、揭陽）、官網展示廠房設備
   - 傾向貿易商：經營範圍僅「批發/貿易/進出口」、地址在寫字樓
   - 判斷不了就寫「無法判斷」，並給驗證方法（要生產車間實拍視頻、營業執照經營範圍截圖）
4. 輸出「背調卡」，固定結構：
   - **基本檔案**：成立年份／註冊資本／地址／主營品類
   - **性質判斷**：工廠／貿易商／不確定 + 依據
   - **風險提示**：涉訴、經營異常、負面口碑（沒查到就明確寫「未查到」，這也是有效信息）
   - **配套技能**：如需評估其報價，可用 quote-compare；如評估產品，可用 product-sourcing
   - **針對性驗廠/問廠提問清單**（按其主營品類）：產能與月產量、主要客戶與市場（內銷/外贸）、現有認證（CE/LFGB/FDA 等）、打樣流程、驗貨與售後、付款方式（新客戶建議 30% 訂金＋見提單副本付尾款）
5. 大額訂單（用戶提到金額較大時）：結尾建議實地驗廠或第三方驗貨。

## 規則
- 所有企業信息必須帶來源連結；查不到就寫查不到，**嚴禁編造企業信息**
- 註明「快速背調，以企查查等官方平台最新記錄為準」
- 只陳述公開信息和推斷依據，不下「是騙子」這類定性結論，風險用事實說話
