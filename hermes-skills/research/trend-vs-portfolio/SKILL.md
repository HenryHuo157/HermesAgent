# 歐美爆款 VS 我方貨盤（趨勢差距分析）

一句話：**外面爆什麼（參數級）VS 我們有什麼 → 該開發什麼、不該碰什麼、不同國情怎麼改。**

## 老闆的戰略背景（口吻與判斷基準）
- 潮流風向標已是**歐美**：TikTok 短視頻帶動產品熱度，日韓台都在跟歐美學——所以調研主戰場是歐美互聯網，用**英文**搜
- 報告禁止空泛：必須結合**我們自身貨盤**做 VS，落到**具體參數**（大小/尺寸/價格/功率/特點），讓採購經理最短時間選對品
- **顆粒度校準樣例（老闆親自舉的例）**：歐美運動水瓶瓶蓋上多了一個小提拉環——因為移動辦公人群工位不固定、端著筆記本走動，舊水瓶只能夾腋下很狼狽，有提拉環一指帶走從容優雅。→ 每個創新點都要寫到這種「誰在什麼場景下痛、設計解決了什麼」的深度

## 輸入
- **必須**：產品品類（如：運動水瓶／空氣炸鍋／便攜榨汁杯）
- **我方貨盤**：優先讀 `/srv/hermes-share/雲端同步/Henry-Huo/公司知識庫/公司貨盤.csv`
  （模板見本技能 `examples/公司貨盤模板.csv`，團隊填好放同目錄即生效）
  - 貨盤文件不存在 → 先問用戶要：「把我們現在這個品類的產品清單發我（品名/規格/售價），或我先出『貨盤未提供』版對比框架」
- **可選**：目標市場（默認 香港+內地；影響國情適配表）

## 階段 1 · 歐美趨勢調研（英文搜索，6–8 輪）
1. `{product} tiktok viral 2026` / `TikTok made me buy it {product}`（社交熱度）
2. `{product} amazon best seller 2026`（北美零售風向）
3. 對冠軍爆款深挖：`{brand} {model} review dimensions price`（參數級）
4. `{product} design trend 2026 innovation`（設計細節，像提拉環這種）
5. `reddit {product} recommendation 2026`（真實用戶痛點與口碑）
6. `{product} wholesale alibaba MOQ`（批發側交叉驗證，僅參考）
7. 補漏：Google Trends 走勢 + 歐洲市場（Amazon.de/UK）是否同步走熱

**記錄鐵律**：每個數據點 = 數值 + 來源 URL + 查詢日期；估算標 `(est.)`；查不到寫「未能核實」，嚴禁編造。

## 階段 2 · 參數級深挖（Top 2–3 爆款）
每款整理：品牌｜型號｜**尺寸**（高×直徑／容量 oz·ml）｜**材質**｜**功率**（電器類）｜**價格**（原價+促銷價）｜評價數｜**核心細節設計**（提拉環級顆粒度：誰的痛、怎麼解決）｜認證（FDA/LFGB/CE）

## 階段 3 · 我方貨盤對照
讀貨盤 CSV，篩出同品類項目，抽同維度字段。貨盤沒有的維度寫「我方未提供」，不猜。

## 階段 4 · 三張 VS 表（報告核心，判定必須逐項給）
1. **有/沒有矩陣**：維度｜歐美爆款現狀（帶參數）｜我方現狀｜**判定**（缺失/落後/持平/領先）｜行動建議
   - 維度從爆款反推：外觀細節（提拉環級）、功能配置、材質認證、價格帶、配件生態、目標人群場景
2. **參數對比表**：Top 爆款 vs 我方最接近款，規格數字硬碰硬
3. **國情適配表**：歐美款直進不同市場要改什麼——
   電壓（110V→220V/查內地 3C）、插頭制式、認證（FDA→CE/UKCA/內地 GB）、份量與尺寸偏好（歐美大容量→港台小廚房）、飲食/使用習慣、包裝語言、價格錨點（歐美 $35 ≠ 香港 HK$35 心理線）

## 階段 5 · 結論（三桶）
- **該開發**：缺失+趨勢上行+貨盤能力夠得著 → 給到具體規格建議（像「瓶蓋加提拉環」這種顆粒度）
- **不該碰**：品牌溢價區正面戰/認證門檻過高/趨勢已退燒 → 說清為什麼
- **觀望**：趨勢存疑（可能刷出來的）→ 給驗證動作

## 輸出：雙報告（用生成器，不手寫代碼）
把結果整理成 JSON（schema 照 `procurement-manager/examples/電飯鍋-報告示範.json`，sections 用
`points/checklist/table/text` 四型；VS 表就是 `table` 型＋header 帶「判定」欄，生成器自動把判定列變色），然後：

```bash
python3 /home/admin/.hermes/skills/procurement/procurement-manager/scripts/make_report.py \
  --json <數據.json> --outdir /srv/hermes-share/採購報告 --prefix 趨勢VS報告
```

交付：HTML 按 SOUL 工件規則 `:::artifact` 預覽 + `MEDIA:` 下載；PPT `MEDIA:` 下載。
報告開頭 `data_note` 必寫：趨勢數據來源（TikTok/Amazon/Reddit 公開信息）+ est./未能核實的分級聲明。
PPT 如需出圖給用戶目檢：用 `research/china-product-research/scripts/render_deck.py <deck.pptx> <out_dir>` 渲染。
